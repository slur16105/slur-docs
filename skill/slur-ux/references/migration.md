# 기존 프로젝트에 SLUR 도입하기 (이관)

이미 돌아가는 마크업에 SLUR 체계를 입히는 작업의 지침이다. 새로 만드는 코드가 아니라 **남의 코드를 옮기는** 상황을 다룬다.

---

## 대원칙 — 이관은 무손실 변환이다

**화면이 바뀌면 실패다.** 바뀌는 것은 이름과 표기법뿐이고, 특이도·DOM 깊이·상태의 의미는 그대로 유지한다.

"이왕 하는 김에" 하고 싶어지는 개선들 — 선택자 깊이 축소, 값 통일(`padding` 15px→16px), 죽은 규칙 정리 — 은 **무손실이 아니다.** 이관과 섞지 말고 별도 작업으로 분리해 화면 확인과 함께 한다.

---

## 1. 접두사는 "어디에 있나"가 아니라 "누가 스타일하나"로 정한다

**가장 자주, 가장 크게 깨지는 지점이다.**

컴포넌트가 페이지 안에 중첩되는 것은 정상이다. 그런데 요소가 컴포넌트 **안에** 있다고 해서 그 요소가 컴포넌트 **소유**인 것은 아니다.

```html
<!-- 테이블(컴포넌트) 안에 있지만… -->
<div class="table_style_01">
  <div class="p_period"><div class="it">…</div></div>
</div>
```
```css
.page_lesson .p_period .it { }   /* 스타일 주인은 페이지다 → p_it */
.table_style_01 .it_list_02 .it { }  /* 이건 컴포넌트 소유 → i_it */
```

같은 `.it`이라도 소유자가 다르다. "가장 가까운 블록"만 보고 일괄 접두사를 붙이면 **CSS와 짝이 어긋나 스타일이 통째로 빠진다.** 이름을 바꾸기 전에 그 요소를 실제로 스타일하는 규칙을 찾아라.

---

## 2. 손대면 안 되는 이름 세 가지

**전역 유틸리티** — `both_area`, `fl_l`, `mb10`, `blind` 계열. global.css 소유이므로 어느 블록 안에 있든 그대로 둔다. 모달 안에 있다고 `both_area`를 `i_foot`으로 바꾸면 `width:100%; overflow:hidden`을 잃고 float 해제가 풀린다.

**JS 훅** — `ui.js`의 셀렉터, HTML 인라인 이벤트 문자열(`onclick="Layer_CLOSE('.popup_app')"`), `data-target` 값. CSS에 규칙이 없어도 살아 있는 이름이다.

**블록 루트 클래스** — 참조가 하나도 없어도 남긴다. component.md의 "컴포넌트는 명확한 루트 클래스를 가진다"가 우선한다. 참조가 없다는 건 오히려 **CSS가 `.layout_x > div` 같은 약한 선택자로 잡고 있다는 신호**이니, 지우지 말고 선택자를 블록 이름으로 바꿔라.

---

## 3. 미사용 판정은 CSS만 보고 하지 않는다

지우기 전에 참조 집합을 모두 모은다.

- CSS 선택자
- JS 셀렉터 (`$('.x')`, `querySelector('.x')`, `closest`, `find` …)
- HTML 인라인 이벤트 안의 문자열
- `data-target` 등 이름을 값으로 담는 속성

하나라도 빠뜨리면 살아 있는 훅을 지운다.

---

## 4. 검증 — 이름 대조만으로는 못 잡는다

세 단계를 모두 돌린다.

**(a) 클래스 집합 대조** — CSS에만 있는 이름 / HTML에만 있는 이름. 오타와 유실을 잡는다.

**(b) 선택자 매칭** — 요소의 **조상 사슬까지** 규칙과 대조한다. (a)만으로는 `i_it`도 `p_it`도 CSS에 존재하므로 통과해버린다. "이름은 있는데 경로가 안 맞는" 유형은 이 검사로만 잡힌다.

**(c) 대조군** — 변환 전 원본에 같은 검사를 돌려 비교한다. 원본부터 죽어 있던 것과 이번에 내가 깨뜨린 것을 구분하는 유일한 방법이다.

검사 도구는 **브라우저의 파싱 규칙을 따라야 한다.** 예를 들어 `<div class="x"/>`처럼 잘못 닫힌 태그를 브라우저는 여는 태그로 취급하지만, 도구가 자기폐쇄로 읽으면 자식 관계를 놓쳐 멀쩡한 클래스를 미사용으로 오판한다.

---

## 5. 작업 순서

1. **사본에 먼저 적용**(드라이런)하고 검증을 통과시킨 뒤 원본에 적용한다.
2. 변환 스크립트는 **읽고 나서 쓴다.** `open(f,'w').write(transform(f))`는 쓰기 모드가 먼저 실행돼 파일을 비운 뒤 빈 내용을 변환한다.
3. 단계마다 커밋한다.

---

## 6. 블록 단위로 끝까지 (부분 적용 금지)

작업 단위를 파일·블록으로 쪼개는 것과 **규칙의 일부만** 적용하는 것은 다르다. 자세한 내용은 SKILL.md의 「블록 단위로 끝까지」 참고.

요약하면: 전역 치환으로 안전한 것만 골라 바꾸고 나머지를 미루지 않는다. `inner_box`·`cont`·`list`처럼 여러 스코프에서 같은 이름이 재사용되는 경우가 반드시 있고, 그건 부모 블록을 따라가며 문맥별로 바꿔야 한다.

---

## 7. 이관 중 발견되는 원본 버그

거의 항상 나온다. 발견하면 **기록하되 고칠지는 따로 판단한다** — 고치는 순간 화면이 바뀌기 때문이다.

자주 나오는 유형:
- 클래스 오타 (`list_stlye_01`) → 그 블록 전체가 스타일 없음
- 자기폐쇄된 비 void 태그 (`<div/>`, `<button/>`)
- 복붙 선택자 오류 (`.page_join input[type=text], .layout_auth input[type=password]`)
- 죽은 외부 이미지 링크
- 대상 마크업이 없는 팝업 호출
