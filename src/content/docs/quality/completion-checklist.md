---

이 체크리스트는 구현 완료와 사용 가능을 구분하기 위한 최소 기준입니다.
프로젝트 특성에 따라 항목을 추가할 수 있지만,
적용한 항목을 근거 없이 생략하지 않습니다.

---

## 검증 조건

- [ ] 대상 URL과 대표 페이지를 기록했다
- [ ] 브라우저·도구 버전을 기록했다
- [ ] 로그인·쿠키·캐시 조건을 기록했다
- [ ] 모바일·태블릿·데스크톱·320px 화면을 확인했다
- [ ] 개선 전후가 같은 조건인지 확인했다

## 구조와 콘텐츠

- [ ] 제목과 랜드마크의 구조가 의미 순서와 맞는다
- [ ] 핵심 정보가 화면 크기에 따라 사라지지 않는다
- [ ] 링크와 버튼이 역할에 맞는 요소로 구현되어 있다
- [ ] 문구가 사용자의 다음 행동과 결과를 설명한다
- [ ] 신뢰 정보와 주요 주장이 사실과 근거에 기반한다

## 반응형

- [ ] 문서에 불필요한 가로 스크롤이 없다
- [ ] 텍스트와 조작 요소가 잘리거나 겹치지 않는다
- [ ] 메뉴와 핵심 탐색을 모든 기준 화면에서 사용할 수 있다
- [ ] 320px 폭에서도 핵심 콘텐츠와 기능을 사용할 수 있다
- [ ] 글자를 확대해도 핵심 콘텐츠가 손실되지 않는다

## 접근성

- [ ] 키보드만으로 핵심 흐름을 완료할 수 있다
- [ ] 현재 초점을 명확히 볼 수 있다
- [ ] 초점 순서가 의미 순서와 맞는다
- [ ] 폼 레이블과 오류 안내가 연결되어 있다
- [ ] 상태를 색상만으로 전달하지 않는다
- [ ] 일반 텍스트 4.5:1, UI 경계·포커스·필수 그래픽 3:1 대비를 라이트·다크·상태별로 통과한다
- [ ] 자동 접근성 검사 결과를 수동 검증과 함께 확인했다

## 기능과 상태

- [ ] 핵심 사용자 흐름을 시작부터 완료까지 실행했다
- [ ] 의도적으로 오류를 발생시키고 복구했다
- [ ] 로딩·빈 상태·오류·성공 상태를 확인했다
- [ ] 모달·메뉴·탭 등 상호작용을 포인터와 키보드로 확인했다
- [ ] 새로고침과 뒤로 가기 이후의 동작을 확인했다

## 404 · 오류 페이지

- [ ] 존재하지 않는 URL·하위 경로·외부 직접 진입에서 404 화면과 실제 404 응답을 확인했다
- [ ] 권한 제한·로그인 만료·일시 장애·점검·연결 끊김의 적용 여부와 제외 이유를 기록했다
- [ ] 영역 오류·빈 결과·페이지 전체 오류를 구분했다
- [ ] 상황 제목·설명·실행 가능한 후속 행동이 있고 추측한 원인·복구 시간·보존 약속이 없다
- [ ] 홈·목록·로그인·권한 요청·문의 링크가 실제 목적지로 이어지고 오류 화면으로 순환하지 않는다
- [ ] 이전 방문 기록이 없는 진입에서도 명시적인 안전한 이동 링크를 사용할 수 있다
- [ ] 재시도 진행·중복 실행 방지·재실패 안내·성공 복귀를 확인했다
- [ ] 쓰기 작업은 처리 결과 확인과 중복 방지 없이 재전송하지 않는다
- [ ] 로그인 후 허용된 내부 경로로 복귀하고 가능한 입력·작업 맥락이 보존된다
- [ ] 고유 title·h1·main, 동적 화면 전환 초점, 재시도 상태 안내와 키보드 조작을 확인했다
- [ ] 320px·모바일·태블릿·데스크톱·글자 확대·라이트/다크에서 안내와 행동을 사용할 수 있다
- [ ] JavaScript·외부 폰트·이미지가 없어도 핵심 안내와 이동 링크를 사용할 수 있다
- [ ] 운영 라우팅·응답 코드·점검 해제 후 복귀를 확인하고 UI 예제 검증과 구분해 기록했다

## 성능

- [ ] LCP 대상 요소가 의도대로 선택되고 즉시 로딩된다
- [ ] 이미지 크기 정보로 레이아웃 이동을 방지했다
- [ ] 대표 페이지를 같은 환경에서 반복 측정했다
- [ ] 중앙값과 변동 범위를 기록했다
- [ ] 실제 사용자 데이터와 실험실 데이터를 분리했다

## 출시 차단

- [ ] 문의·구매 등 핵심 흐름이 정상 작동한다
- [ ] 모바일에서 핵심 기능을 사용할 수 있다
- [ ] 키보드로 핵심 흐름을 완료할 수 있다
- [ ] WCAG AA 색 대비 자동 검사가 통과한다
- [ ] 개인정보와 인증정보가 노출되지 않는다
- [ ] 운영 사이트 전체가 의도하지 않게 `noindex` 처리되지 않았다
- [ ] 서비스 중단으로 이어질 심각한 오류가 없다

## 결과 기록

- [ ] 문제의 URL과 화면 조건을 기록했다
- [ ] 기대 결과와 실제 결과를 구분했다
- [ ] 재현 순서와 증거를 남겼다
- [ ] 사용자·서비스 영향을 설명했다
- [ ] 권장 조치와 재검증 조건을 기록했다

자동 점수는 이 체크리스트를 대신하지 않습니다.
완료는 **실제로 사용하고 근거를 남긴 뒤** 선언합니다.
