이 체크리스트는 구현 완료와 사용 가능을 구분하기 위한 최소 기준입니다.
프로젝트 특성에 따라 항목을 추가할 수 있지만,
적용한 항목을 근거 없이 생략하지 않습니다.

---

## 검증 조건

- [ ] 대상 URL과 대표 페이지를 기록했다
- [ ] 브라우저·도구 버전을 기록했다
- [ ] 로그인·쿠키·캐시 조건을 기록했다
- [ ] 모바일·태블릿·데스크톱·320px 화면을 확인했다
- [ ] 개선 전후가 같은 조건인지 확인했다

## 구조와 콘텐츠

- [ ] 제목과 랜드마크의 구조가 의미 순서와 맞는다
- [ ] 핵심 정보가 화면 크기에 따라 사라지지 않는다
- [ ] 링크와 버튼이 역할에 맞는 요소로 구현되어 있다
- [ ] 문구가 사용자의 다음 행동과 결과를 설명한다
- [ ] 신뢰 정보와 주요 주장이 사실과 근거에 기반한다

## 반응형

- [ ] 문서에 불필요한 가로 스크롤이 없다
- [ ] 텍스트와 조작 요소가 잘리거나 겹치지 않는다
- [ ] 메뉴와 핵심 탐색을 모든 기준 화면에서 사용할 수 있다
- [ ] 320px 폭에서도 핵심 콘텐츠와 기능을 사용할 수 있다
- [ ] 글자를 확대해도 핵심 콘텐츠가 손실되지 않는다

## 접근성

- [ ] 키보드만으로 핵심 흐름을 완료할 수 있다
- [ ] 현재 초점을 명확히 볼 수 있다
- [ ] 초점 순서가 의미 순서와 맞는다
- [ ] 폼 레이블과 오류 안내가 연결되어 있다
- [ ] 상태를 색상만으로 전달하지 않는다
- [ ] 자동 접근성 검사 결과를 수동 검증과 함께 확인했다

## 기능과 상태

- [ ] 핵심 사용자 흐름을 시작부터 완료까지 실행했다
- [ ] 의도적으로 오류를 발생시키고 복구했다
- [ ] 로딩·빈 상태·오류·성공 상태를 확인했다
- [ ] 모달·메뉴·탭 등 상호작용을 포인터와 키보드로 확인했다
- [ ] 새로고침과 뒤로 가기 이후의 동작을 확인했다

## 성능

- [ ] LCP 대상 요소가 의도대로 선택되고 즉시 로딩된다
- [ ] 이미지 크기 정보로 레이아웃 이동을 방지했다
- [ ] 대표 페이지를 같은 환경에서 반복 측정했다
- [ ] 중앙값과 변동 범위를 기록했다
- [ ] 실제 사용자 데이터와 실험실 데이터를 분리했다

## 출시 차단

- [ ] 문의·구매 등 핵심 흐름이 정상 작동한다
- [ ] 모바일에서 핵심 기능을 사용할 수 있다
- [ ] 키보드로 핵심 흐름을 완료할 수 있다
- [ ] 개인정보와 인증정보가 노출되지 않는다
- [ ] 운영 사이트 전체가 의도하지 않게 `noindex` 처리되지 않았다
- [ ] 서비스 중단으로 이어질 심각한 오류가 없다

## 결과 기록

- [ ] 문제의 URL과 화면 조건을 기록했다
- [ ] 기대 결과와 실제 결과를 구분했다
- [ ] 재현 순서와 증거를 남겼다
- [ ] 사용자·서비스 영향을 설명했다
- [ ] 권장 조치와 재검증 조건을 기록했다

자동 점수는 이 체크리스트를 대신하지 않습니다.
완료는 **실제로 사용하고 근거를 남긴 뒤** 선언합니다.
