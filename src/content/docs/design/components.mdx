컴포넌트는 **모양만** 담은 CSS입니다.
이름과 구조는 슬러 문법(블록 · `i_` 내부 요소 · `m_` 수정자 · `data-state`)을 따르고,
동작은 [네이티브 → `slur.js` → 위임](/js/behaviors/)에서 옵니다.
기본 동작은 외부 JS 라이브러리 없이 사용합니다. 커스텀 날짜 선택기만 동봉한 Vanilla Calendar Pro 3.3.1을 선택적으로 사용합니다.

기존 15개와 확장 11개(파일 첨부 포함), **총 26개 유형**입니다. 드로어와 시트는 CSS를 공유하므로 컴포넌트 CSS 파일은 25개입니다.

## 함께 지키는 것

- **공유 컨트롤 높이 `2 / 2.5 / 3rem`** — 버튼·입력·셀렉트가 같은 줄에서 키가 맞습니다. 모바일 터치 타깃은 48.
- **상태색 면 위 텍스트는 on-토큰**, 포커스 링은 `global.css` 한 곳, 아이콘은 `em` + `currentColor`.
- **컴포넌트 내부를 덮을 때는 페이지 스코프에서** — `.page_list .table_data { min-width: 760px; }`. 컴포넌트 CSS 파일 자체를 고치지 않습니다.
- **토스트 컨테이너는 미리 DOM에** — 라이브 영역이 먼저 있어야 다음 알림이 보조 기술에 읽힙니다. 모달이 열린 동안은 토스트를 띄우지 않습니다(`slur.toast()`가 닫힐 때까지 기다립니다).

### 4상태 — 블록에 `data-state`, 안내는 `i_status` 상자 안

```html
<section class="p_programs" data-state="loading" aria-label="프로그램 목록">
  <div class="i_status" role="status">            <!-- 항상 렌더 — 상태 전환이 보조 기술에 읽힌다 -->
    <div class="i_loading"><span class="spinner" aria-hidden="true"></span> 불러오는 중…</div>
    <div class="i_empty"><div class="empty_state">…</div></div>
    <div class="i_error"><div class="empty_state m_error">…</div></div>
  </div>
  <ul class="i_body">…</ul>                        <!-- success일 때만 보인다 -->
</section>
```

`data-state` 값만 `loading` → `empty` / `error` / `success`로 바꾸면 `common.css`의 스위치가 슬롯을 고릅니다. 룩(스피너·빈 상태 패널·스켈레톤)은 `state.css`가 줍니다 — 로딩 기본은 스피너 + 읽힐 문장, 스켈레톤은 넓은 표·목록의 선택지입니다([화면 상태 설계](/ux/screen-states/)).

### 토스트 — 컨테이너 선존재 + `slur.toast()`

```html
<div class="toast_message" role="status" data-state="close">
  <span class="i_icon">…</span><p class="i_text"></p>
  <button type="button" class="i_close" aria-label="닫기">…</button>
</div>
<div class="toast_message" role="alert" data-state="close">…</div>
```

```js
slur.toast('저장됐습니다');                          // status — 자동 소멸
slur.toast('저장에 실패했습니다', { level: 'alert' }); // alert — 직접 닫기
```

### 모달 — `<dialog>`가 1순위

```html
<dialog class="modal_dialog" id="renameDialog" aria-labelledby="renameTitle">
  <div class="i_head">
    <h2 class="i_title" id="renameTitle">프로젝트 이름 변경</h2>
    <button type="button" class="i_close" aria-label="닫기">…</button>
  </div>
  <div class="i_body">…</div>
  <div class="i_foot">
    <button type="button" class="btn">취소</button>
    <button type="button" class="btn m_primary">저장</button>
  </div>
</dialog>
```

`dialog.showModal()` 하나로 배경 차단(inert)·Esc·포커스 복귀·최상위 레이어를 브라우저가 처리합니다. 상태 정본은 `[open]`이고 배경 딤은 `::backdrop`(`--color-surface-overlay`)입니다 — [팝업 / 모달 패턴](/patterns/popup-modal/).

## 확장 컴포넌트 연결

스타일은 기존과 같이 `global.css → common.css → page.css` 순서로 연결합니다. 전체 공통 묶음에는 달력 구조 CSS와 SLUR 스킨이 포함되며, 프로젝트별로 묶을 때는 필요한 원본만 선택합니다.

아래 경로는 배포된 `slur-design/assets/` 기준입니다. 스크립트는 마크업이 준비된 뒤 한 번 초기화하므로 `defer`로 로드합니다. 동적으로 추가하거나 재마운트하는 화면은 프로젝트에서 초기화 생명주기를 별도로 연결해야 합니다.

```html
<!-- 콤보박스·슬라이더·아바타 이미지 폴백·드로어/시트 -->
<script src="/skill/slur-design/assets/js/components.js" defer></script>
<!-- 파일 첨부를 쓰는 화면 -->
<script src="/skill/slur-design/assets/js/file-upload.js" defer></script>
<!-- 커스텀 날짜 선택기를 쓰는 화면: 라이브러리를 먼저 연결 -->
<script src="/skill/slur-design/assets/vendor/vanilla-calendar-pro/3.3.1/index.js" defer></script>
<script src="/skill/slur-design/assets/js/date-time.js" defer></script>
```

- **콤보박스:** 정적인 단일 선택 목록용입니다. 입력 필터·방향키·Enter 선택·Esc/포커스 이탈 닫기를 지원합니다. 선택 시 `slur:comboboxchange`의 `event.detail.value`를 받습니다. 서버 검색·다중 선택·가상 스크롤은 별도 위임 대상으로 둡니다.
- **날짜·시간:** 날짜 입력에는 `data-js="date-picker"`를 붙이고, 시간은 `.time_picker` 안에 `role="combobox"` 입력·목록·안내 영역을 둡니다. 인스턴스별 label·aria-controls·aria-describedby ID는 고유하게 지정합니다. 라이브러리가 없으면 날짜는 네이티브 date 입력으로 폴백합니다. 시간은 30분 간격 목록과 자유로운 분 입력을 지원합니다. 확정 시 `change` 이벤트를 보냅니다.
- **드로어·시트:** `<dialog>`를 사용합니다. 트리거의 `data-overlay-open` 값은 dialog ID이며, 내부 닫기 버튼에는 `data-overlay-close`를 붙입니다. 배경 차단·포커스 제한·포커스 복귀는 브라우저가 담당합니다. `data-state`는 열기·닫기 애니메이션 단계를 나타냅니다.
- **파일 첨부:** `slur:filechange`의 `event.detail.files`로 선택 파일을 받습니다. 클릭 선택·드롭·삭제·폼 초기화를 처리하며 실제 업로드·파일 형식/크기 검증은 프로젝트가 담당합니다.
- **프로그레스:** `<progress>`에 label 또는 `aria-label`을 제공합니다. 완료와 진행 중 모두 브랜드 색상을 사용합니다.

전체 마크업은 위 라이브 데모의 `system/demo.html`에서 복사할 수 있습니다.

## 없는 컴포넌트가 필요할 때

**토큰만으로 새로 조립**합니다. 이름은 슬러 네이밍(블록 + `i_` + `m_`), 위치는 프로젝트의 컴포넌트 CSS, 새 토큰·새 색상값은 만들지 않습니다. 콤보박스처럼 동작이 큰 위젯은 3순위 [위임](/js/external-libraries/) — 동작만 빌리고 구조·네이밍·`data-state`·모양은 슬러를 유지합니다. 같은 부품이 두 곳 이상에서 반복되면 그때 시스템으로 승격을 제안합니다.
