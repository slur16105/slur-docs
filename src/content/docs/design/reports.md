SLUR 보고서는 브랜드 로고와 보고서 강조색을 분리합니다. **SLUR 로고는 원본 블랙**을 유지하고, 블루는 제목·구분선·정보 강조에만 사용합니다. 넓은 면은 흰색과 연회색으로 두며 빨간색은 실제 위험을 알리는 작은 표시에만 제한합니다.

## 요약본은 일반어로 씁니다

요약본은 비개발자가 먼저 읽는 문서입니다. `모바일 이용성`은 `휴대폰에서 쓰기 쉬운지`, `가독성`은 `읽기 편의`, `SEO 메타데이터`는 `검색 결과 정보`, `CTA`는 `상담 버튼`처럼 바꿉니다. 정확한 측정값, 기술 설명, 확인 근거는 상세 보고서에서 제공합니다.

상세본에서 `P0~P3`을 사용할 때는 모든 항목에 `P0 · 즉시 조치`, `P1 · 우선 개선`, `P2 · 계획 개선`, `P3 · 추후 확인`처럼 코드와 일반어를 함께 씁니다. 뜻이 항목마다 보이므로 별도의 사전 설명표는 두지 않습니다. 권장 진행 순서도 `즉시 → 우선 → 계획 → 추후`로 표시합니다.

평가하지 않은 조합이 많은 결과표에는 빈칸이나 `-`를 반복하지 않습니다. `평가 분야 | 확인한 페이지·범위 | 결과` 구조로 실제 평가한 값만 표시해 0점과 미평가가 혼동되지 않게 합니다.

## 생성 과정

현재 AUDIT 보고서는 HTML 화면을 캡처하지 않습니다. 데이터와 레이아웃 코드에서 A4 벡터 PDF를 직접 생성하고, 완성된 PDF를 페이지 이미지로 렌더링해 글자 잘림·겹침·로고 색·경고색 비중을 검수합니다.

색상값, 기술 용어 대응표, 상세 검수 항목은 배포되는 `slur-design` 스킬의 [`references/reports.md`](/skill/slur-design/references/reports.md)에 기록되어 있습니다.
