## 핵심 원칙

<CardGrid>
  <Card title="구조 우선" icon="document">
    클래스 이름만 봐도 구조와 역할이 읽히도록 설계합니다.
    UI를 스타일의 집합이 아닌 **안정적인 구조**로 다룹니다.
  </Card>

  <Card title="역할 분리" icon="setting">
    구조는 HTML, 표현은 CSS, 동작은 JavaScript,
    상태는 **`data-state`**가 담당합니다.
  </Card>

  <Card title="일관된 규칙" icon="pencil">
    누가 작성해도 같은 구조로 읽힙니다.
    **일관성이 생산성**을 만듭니다.
  </Card>

  <Card title="완결성" icon="star">
    정상 상태만이 아니라 로딩·에러 상태, 접근성, 성능까지
    **처음부터 설계**합니다.
  </Card>
</CardGrid>

## SLUR UX/UI System은 프레임워크가 아닙니다

특정 기술이나 라이브러리에 종속되지 않는
**UI 설계 기준이자 문서화 방법론**입니다.
어떤 환경에서도 적용할 수 있습니다.
