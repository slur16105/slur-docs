## v1.0.0

### 초기 공개 버전

SLUR UX/UI System의 첫 번째 공식 버전입니다.

#### 정립된 내용

- UI 구조 단위 구분
  - 레이아웃(layout_)
  - 페이지(page_)
  - 컴포넌트(접두사 없음)
- 내부 요소(i_) / 수정자(m_) 규칙 정립
- 구조 중첩 금지 원칙 명문화
- 클래스는 구조, 상태는 data-*로 분리하는 기준 정립
- Reference 문서 구조 확립
  - 클래스 네이밍 예제
  - 권장 / 비권장 사례
  - 체크리스트
  - FAQ
