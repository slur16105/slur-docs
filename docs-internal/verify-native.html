네이티브 dialog · inert · popover 검증

키보드로 확인하세요: Tab / Shift+Tab 이동, Esc 닫기. 하단 바에 현재 포커스 위치가 실시간 표시됩니다.

① 네이티브 <dialog> + showModal() — 상태 정본은 [open]

JS는 showModal()/close()만 부르고, 표시는 브라우저의 open 속성이 담당. 닫기 버튼은 JS 없이 <form method="dialog">.

open 속성: 없음
확인할 것
  • ☐ 열린 동안 배경 버튼이 클릭·Tab 모두 안 되는가 (자동 inert)
  • ☐ Esc로 닫히는가
  • ☐ 닫힌 뒤 포커스가 연 버튼으로 돌아오는가 (하단 바 확인)
  • ☐ Tab을 계속 누르면 브라우저 UI(주소창)로는 나간다 — 이건 정상(W3C 결론)

② <dialog> + data-state 병용 — 어긋남 시연 (리스크의 실체)

이 모달은 표시를 data-state로 제어하고, 여는 쪽은 둘 다 갱신한다. 그런데 Esc는 브라우저가 처리하므로 open 속성만 사라진다. Esc로 닫아 보세요.

open 속성: 없음data-state: close← 어긋남!
예상 결과
  • ☐ Esc를 누르면 open은 사라지는데 data-state는 "open"으로 남는다
  • ☐ 최상위 레이어에서 내려온 모달이 페이지 본문에 유령처럼 박혀 남는다 (CSS가 data-state만 믿으므로)
  • ☐ 「동기화 켜기」 후에는 close 이벤트가 data-state를 되돌려 정상 동작 — 단 이 한 줄을 잊으면 곧바로 이 버그

③ 커스텀 div[role=dialog] + inert — 지금 슬러 방식 + 배경 차단

상태는 data-state, 열릴 때 배경(.layout_app)에 inert를 붙이고 Tab을 안에서 순환시키며, 닫을 때 연 버튼으로 포커스 복귀. 전부 JS ≈20줄.

data-state: close배경 inert: false
확인할 것
  • ☐ 열린 동안 배경이 클릭·Tab 모두 안 되는가 (inert 효과)
  • ☐ Tab이 모달 안에서 순환하는가
  • ☐ Esc 닫기 + 포커스 복귀가 되는가 (직접 구현한 것)

④ popover="auto" — 드롭다운 닫기 규칙

JS 0줄. 버튼의 popovertarget만으로 열리고, Esc·바깥 클릭 닫기(light-dismiss)는 브라우저가 처리.

popover 상태: closed
확인할 것
  • ☐ 바깥 아무 곳이나 클릭하면 닫히는가
  • ☐ Esc로 닫히고, 키보드로 닫으면 포커스가 버튼으로 돌아오는가
  • ☐ 모달과 달리 배경은 그대로 조작 가능한가 (비모달)

⑤ 스타일 동일성 — 같은 룩을 div와 dialog로

dialog의 브라우저 기본 스타일(테두리·패딩·크기·중앙 정렬)은 명세에 적힌 값이라 전 브라우저 동일하고, 전부 CSS로 재정의된다. 두 버전을 번갈아 열어 카드·딤·그림자·위치가 픽셀 단위로 같은지 확인.

확인할 것
  • ☐ 카드 크기·모서리·그림자·딤 색·중앙 위치가 두 버전에서 동일한가
  • ☐ 이 페이지를 Safari로도 열어 (localhost:8931/verify-native.html) 같은지 — 크로스브라우징 핵심 확인

⑥ 열림·닫힘 애니메이션 — 과거 dialog를 못 쓰게 하던 문제

display:none ↔ 표시 전환은 원래 transition이 불가능했다. 지금은 @starting-style + allow-discrete로 해결 (Chrome 117+ · Safari 17.4+). 미지원 브라우저에선 애니메이션만 생략되고 동작은 그대로 — 점진 향상.

확인할 것
  • ☐ 열릴 때 페이드+슬라이드, 닫힐 때(Esc 포함) 역방향으로 부드럽게 사라지는가
  • ☐ Safari에서도 같은 움직임인가
