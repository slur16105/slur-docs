# 레이아웃 테마 실험 기준

레이아웃 테마는 색상이나 외형을 바꾸지 않고 화면의 여백, 정보 밀도, 열 구성만 조절한다. 유형 하나는 CSS 파일 하나이며 `base.css`가 역할 토큰을 기존 실험실 구조에 연결한다.

## 현재 레이아웃

- `comfortable.css`: 균형 잡힌 기본 여백과 배치
- `compact.css`: 좁은 여백과 높은 정보 밀도
- `spacious.css`: 넓은 여백과 단순한 콘텐츠 열

## 승인 조건

- 각 파일은 자신의 `data-layout-theme` 선택자와 승인된 `--layout-*` 토큰만 선언한다.
- 컬러값, 외형 토큰, 일반 CSS 속성, `@import`, `!important`, URL은 넣지 않는다.
- 720px 이하에서는 공통 모바일 구조를 유지해 가로 스크롤과 터치 영역 회귀를 방지한다.
- 721~1100px에서는 모든 레이아웃의 사이드바 여백을 공통 아이콘 레일 너비에 맞춘다. 메뉴 이름은 보조 기술에서 읽을 수 있게 유지한다.
- 콘텐츠가 좁아지면 컨테이너 쿼리로 포커스 카드·지표·프로젝트 행을 접는다. 상태 배지는 텍스트 길이에 맞춰 표시하며 모바일에서도 다음 줄에 유지한다.
- `npm run check:themes`와 `npm run build`를 통과한 다음 Git에 기록한다.

자동 검사는 토큰 규칙과 색 대비를 확인한다. 총 조합 수는 선택 가능한 조합의 개수이며, 모든 화면의 렌더링 또는 WCAG 전체 항목을 검사했다는 의미는 아니다. 승인 전 실제 브라우저에서 좁은 화면·분기점 전후·포커스를 별도로 확인한다.
