# 외형 테마 승인 기준

이 폴더는 공식 배포 전 외형을 검증하는 내부 실험 영역이다. 외형 하나는 CSS 파일 하나이며, 컴포넌트 CSS를 복사하지 않고 정해진 `--appearance-*` 역할 토큰만 배선한다.

## 자동 승인 조건

- 파일명과 선택자 값이 같아야 한다. `soft.css`는 `data-appearance-theme="soft"`만 선언한다.
- 파일에는 하나의 테마 규칙과 승인된 `--appearance-*` 토큰만 들어간다. 일반 CSS 속성, `@import`, `!important`, URL은 금지한다.
- 원시 컬러값과 컬러 함수는 금지한다. 테두리는 검증된 시맨틱 `--color-border-*` 토큰만 참조한다.
- 필수 외형 토큰을 빠짐없이 선언하고 실험실 선택 목록과 `<link>`에 등록한다.
- `npm run check:themes`에서 컬러 테마별 Light/Dark 색 대비와 모든 외형 파일 계약을 함께 통과해야 한다.
- `npm run build`가 실패하면 병합·배포하지 않는다. CI도 같은 빌드 명령을 실행한다.

색 대비 하한은 WCAG 2.2 AA를 따른다. 일반 텍스트는 4.5:1, 큰 텍스트와 식별에 필요한 UI 경계·포커스·필수 그래픽은 3:1이다. 외형 파일은 색·타이포·밀도·레이아웃·DOM을 바꿀 수 없으므로 키보드 동작과 읽기 순서를 훼손하지 않는다.

## 현재 외형

- `standard.css`: 기본 라운드와 은은한 입체감
- `flat.css`: 작은 라운드와 테두리 중심의 평면감
- `soft.css`: 큰 라운드와 부드러운 그림자
- `sharp.css`: 각진 모서리와 선명한 경계
- `outline.css`: 두꺼운 테두리와 그림자 없는 선 중심 외형
- `capsule.css`: 알약 모양 컨트롤과 크게 둥근 카드
- `elevated.css`: 중간 라운드와 여러 층의 그림자로 높이감을 강조
- `brutal.css`: 각진 모서리, 굵은 테두리와 번짐 없는 오프셋 그림자

Elevated·Brutal은 일반 버튼에도 외형 그림자를 연결한다. `:focus-visible`에서는 장식 그림자를 제외해 기존 키보드 포커스 링이 우선한다. 그림자와 테두리는 시맨틱 토큰만 참조해 Light/Dark 및 컬러 선택과 독립적으로 동작한다.

## 새 외형 추가 순서

1. 이 폴더에 `<이름>.css`를 추가한다.
2. 실험실 HTML에 CSS 링크와 선택 버튼을 각각 한 줄 등록한다.
3. `npm run check:themes`와 `npm run build`를 통과시킨다.
4. Light/Dark에서 포커스 표시, 경계 식별, 320px 리플로우를 확인한다.
5. 검증 결과와 함께 Git에 기록한다.

자동 검사는 WCAG 전체 적합성 인증을 대신하지 않는다. 외형의 승인 범위를 벗어나는 구조·동작 변경은 접근성 체크리스트로 별도 검토한다.

## 실험실 컬러 모드 선택

컬러 모드는 상단 우측의 해·달 아이콘 버튼으로 선택한다. 두 버튼은 44px 터치 영역, 툴팁, 접근 가능한 이름과 `aria-pressed` 상태를 유지한다. 장식 SVG는 보조 기술에서 숨기고, 숨김 Light/Dark 텍스트는 기존 모드 변경 알림에 사용한다. 모바일에서도 제목과 겹치지 않아야 하며 Tab·Enter·Space 조작과 포커스 링을 확인한다.

## 디바이스 크기 비교

외형·레이아웃·컬러 테마·디바이스·화면 보기는 각각 왼쪽 정렬 블록으로 표시한다. 작은 화면에서는 블록 제목 다음 줄에 버튼이 왼쪽부터 줄바꿈된다. 선택 영역은 스크롤과 함께 이동해 좁은 화면을 가리지 않는다.

- 자동: 미리보기 영역의 가용 폭, 콘텐츠에 맞춘 높이. 최소 폭은 기존 레이아웃 계약인 320px이며, 가용 폭이 더 작으면 너비 맞춤에서 축소한다.
- 데스크톱: 1440 × 900 CSS px.
- 태블릿: 768 × 1024 CSS px.
- 모바일: 390 × 844 CSS px.
- 너비 맞춤: 실제 프리셋 폭은 고정하고 표시 배율만 줄인다. 100%: 원래 CSS px 크기로 표시하며, 공간이 부족하면 미리보기 영역을 가로 스크롤한다. 긴 내용은 프리셋 화면 안에서 세로 스크롤한다.

HTML의 샘플 `.lab_stage` 한 곳을 스크립트가 독립 `srcdoc` iframe으로 복제한다. CSS 링크를 공유하므로 미디어 쿼리는 부모 브라우저가 아닌 iframe 크기에 반응한다. iframe에 도구 모음·스크립트는 복제하지 않는다. 내부 앵커는 `about:srcdoc#…`를 사용해 실험실 전체가 중첩 로드되지 않게 한다. 테마 변경 시 iframe을 다시 만들지 않고 루트/본문 데이터 속성만 동기화해 디바이스와 스크롤 상태를 유지한다. 새로고침 시 기본 선택으로 돌아온다.

`device-preview.mjs`가 프리셋과 배율 계산을 관리하며 `npm run check:devices`는 42가지 계산과 HTML 등록 일치를 검사한다. 이 검사는 `check:themes` 및 빌드 전 검사에 포함된다. 브라우저에서는 320·720·970·1440px에서 왼쪽 정렬, 고정 프리셋, 너비 맞춤/100%, 키보드 조작, 내부 메뉴 이동과 테마 동기화를 확인한다. 크기 비교용이며 실제 기기의 터치·DPR·사용자 에이전트 또는 WCAG 전체 적합성을 에뮬레이션/인증하지 않는다.
