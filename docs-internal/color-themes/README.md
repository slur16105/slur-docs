# 컬러 테마 승인 기준

이 폴더는 외형과 독립적으로 선택하는 컬러 테마의 내부 실험 영역이다. 컬러 테마 하나는 CSS 파일 하나이며, 같은 파일 안에서 Light와 Dark 값을 함께 관리한다. 두 색 조합도 파일 하나와 선택 버튼 하나로 관리한다.

## 구조

- 단색 테마는 브랜드 컬러 프리미티브와 `--color-brand-soft`를 교체한다.
- 조합 테마는 주색 외에 보조색 역할 4개를 Light/Dark에 모두 선언한다: `--color-accent`(진행률 선), `--color-accent-soft`(보조 강조 배경·진행률 트랙), `--color-text-accent`(보조 강조 글자·아이콘), `--color-chart-accent`(차트 보조 계열).
- `base.css`는 단색 테마의 보조 강조를 기존 브랜드색·차트색에 연결하는 공통 기본값이다. 단색 Dark의 진행률 선은 배경 대비를 위해 브랜드 400 단계를 사용한다. 선택 가능한 테마 파일은 아니다.
- 주요 버튼·메뉴·히어로 배경은 주색, 포커스 배지·진행률·통계 아이콘·차트 보조 계열은 보조색을 사용한다. 경고·성공 등 상태색은 보조색과 별개로 유지한다.
- 중립색·상태색·타이포·간격·외형·레이아웃은 변경하지 않는다.
- Light에서 선택한 컬러 계열은 Dark로 전환해도 유지한다.
- 컬러칩은 현재 모드에 적용되는 대표색을 보여준다. 단색은 칩 1개, 조합은 주색·보조색 칩 2개를 함께 표시한다.

## 새 컬러 추가 순서

현재 단색 Blue, Green, Purple, Amber(따뜻한 주황 계열), Rose(붉은 분홍 계열)와 두 색 조합 Ocean(Blue + Teal), Sunset(Rose + Amber), Forest(Green + Gold), Aurora(Purple + Cyan)를 제공한다. 밝은 색의 분위기는 연한 배경과 Dark의 강조색으로 표현하고, Light의 버튼색은 흰 글자를 읽을 수 있도록 충분히 짙게 조정한다. Forest의 골드는 금속 질감이 아닌 색상 역할이며, Aurora의 보조색은 푸른 청록 계열이다.

1. 이 폴더에 `<이름>.css`를 추가하고 Light/Dark 값과 칩 색을 선언한다. 조합 테마는 `ocean.css`처럼 보조색 역할 4개와 보조 칩의 Light/Dark 값도 모두 선언한다.
2. 실험실 HTML에 CSS 링크와 컬러 선택 버튼을 등록한다. 조합 테마는 두 번째 칩에 `m_accent`를 붙이고 접근 가능한 이름에 조합을 명시한다.
3. `npm run check:themes`에서 테마 계약과 검사 대상 텍스트·UI·진행률·차트의 Light/Dark 대비를 통과한다.
4. 브라우저에서 외형·레이아웃과 함께 전환하며 실제 색 적용, 키보드 포커스, 좁은 화면의 줄바꿈을 확인한다.
5. `npm run build`를 통과한 뒤 Git에 기록한다.

일반 텍스트는 4.5:1, 큰 텍스트와 식별에 필요한 UI 경계·포커스·필수 그래픽은 3:1을 하한으로 사용한다. 검사에서 실패한 컬러는 실험실 선택지로 승인하지 않는다.

자동 검사는 정의된 색 조합과 테마 계약을 검증하며, 모든 화면·상태의 WCAG 2.2 AA 준수를 보증하지는 않는다. 색상만으로 의미를 전달하지 않는지, 실제 배치와 상호작용도 별도로 확인한다.
