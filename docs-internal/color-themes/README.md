# 컬러 테마 승인 기준

이 폴더는 외형과 독립적으로 선택하는 컬러 테마의 내부 실험 영역이다. 컬러 하나는 CSS 파일 하나이며, 같은 파일 안에서 Light와 Dark 값을 함께 관리한다.

## 구조

- 컬러 테마는 브랜드 컬러 프리미티브와 `--color-brand-soft`만 교체한다.
- 중립색·상태색·타이포·간격·외형·레이아웃은 변경하지 않는다.
- Light에서 선택한 컬러 계열은 Dark로 전환해도 유지한다.
- 컬러칩은 현재 모드에 실제 적용되는 대표색을 보여준다.

## 새 컬러 추가 순서

1. 이 폴더에 `<이름>.css`를 추가하고 Light/Dark 값과 칩 색을 선언한다.
2. 실험실 HTML에 CSS 링크와 컬러 선택 버튼을 등록한다.
3. `npm run check:themes`에서 모든 실제 조합의 WCAG 2.2 AA 대비를 통과한다.
4. `npm run build`를 통과한 뒤 Git에 기록한다.

일반 텍스트는 4.5:1, 큰 텍스트와 식별에 필요한 UI 경계·포커스·필수 그래픽은 3:1을 하한으로 사용한다. 검사에서 실패한 컬러는 실험실 선택지로 승인하지 않는다.
